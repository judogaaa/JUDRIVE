## Данные и запуск

Текущее дерево и Docker build context исключают PDF, индексы, SQLite, исходные карточки автопарка и файл состояния браузера. `vehicles.json`, `fault_types.json` и `e2e/storage-state.json` присутствовали в старых коммитах. Старые коммиты сохранены по условиям задания. Проверки Docker использовали тестовые учётные данные, временный каталог и локальный HTTP. GitHub Actions добавлен для автоматических проверок после публикации ветки.

Автопарк, диагностика, её история, чат, голос, заявки и источники доступны через подписанную сессию механика. В контексте проверки сервер связывает источник с двигателем выбранной пары ТС/сессия. Прямой каталог после авторизации поддерживает выбор руководства по двигателю. `/api/live` проверяет процесс, `/api/ready` сверяет модель с авторизованным каталогом GigaChat и проверяет остальные зависимости.
