Локальная нагрузочная проверка измеряет только маршрут liveness через Caddy. Она не измеряет задержку реального GigaChat, нагрузку на RAG или производительность VPS.

## Воспроизведение

```bash
python -m pytest -q
npm --prefix frontend run lint -- --deny-warnings
npm --prefix frontend test
npm --prefix frontend run build
npm run e2e
python scripts/verify_submission_regressions.py --synthetic-pdfs
bash scripts/verify_compose.sh
```

Docker smoke создаёт временный автопарк, PDF, SQLite и тестовую сессию. Он проверяет зависимости, закрытые маршруты, выдачу разрешённого PDF, запись заявки в тестовый Mock ТОиР, снимок, восстановление в отдельный файл и доступ к истории после рестарта. Удалённый стенд и реальные заявки в этом прогоне не используются. [Развёртывание, резервное копирование и мониторинг](DEPLOY_HTTPS.md) · [Приёмка с реальными руководствами](SOURCES.md)
