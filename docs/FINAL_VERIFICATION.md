# JUDRIVE · финальная локальная приёмка

Проверка выполнена на ветке `fix/submission-hardening` поверх `42fef7ee8f4671e2fe3b5e0ffc444a929e312dd4`. История обеих объединённых веток сохранена. Удалённые ветки и VPS не изменялись.

## Что исправлено

- Голосовой API проверяет сессию до чтения multipart. Размер ограничивается по заголовку и по принятым байтам. Некорректный ответ STT завершается контролируемой ошибкой. При отсутствии поддерживаемых вариантов браузер может выбрать собственный формат записи.
- При выдаче цитаты SHA-256 сверяется с текущим PDF. Цитата становится недоступной при удалении или замене документа. Проверки RAG читают метаданные без повторной записи схемы. Поиск агента и проверка цитаты выполняются в рабочих потоках.
- На узком экране вердикт появляется перед подходящими источниками. Добавлен телефонный сценарий с проверкой позиции вердикта, навигации, страницы PDF, журнала, автопарка и кабинета.
- README дополнен структурой проекта и скриншотом телефона. Актуализированы требования и пакет сдачи. Удалены файлы шаблона Vite и старый скрипт копирования рабочей SQLite в E2E. Лицензия Manrope и исходные Mock API сохранены.

Первый запуск собранных образов остановился из-за нехватки места Docker VFS. Для повторного локального запуска слои runtime-образа сведены в один с сохранением файловой системы, команд и окружения. После правки мобильной вёрстки веб-образ пересобран обычным Docker build. Настройки проекта и инструкция запуска сохраняют штатную сборку.

Проверка интерфейса выполнена в Chromium на desktop- и mobile-размерах. Телефонный сценарий использует ширину 390 px, мобильный viewport и touch. Отдельного прогона на физических устройствах не было.

## Воспроизведение

~~~bash
python -m pytest -q
npm --prefix frontend run lint -- --deny-warnings
npm --prefix frontend test
npm --prefix frontend run build
npm run e2e
python scripts/verify_submission_regressions.py --synthetic-pdfs
bash scripts/verify_compose.sh
~~~

Для обновления мобильного скриншота запустите `JUDRIVE_SCREENSHOT_DIR="$PWD/docs/screenshots" npm run e2e -- e2e/mobile-workspace.spec.ts`. Предметный RAG запускается отдельно через `scripts/verify_rag_queries.py`. [Подготовка окружения](../README.md) · [Матрица хакатона](REQUIREMENTS_MATRIX.md)
