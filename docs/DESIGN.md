# Дизайн JUDRIVE

Профессиональный, спокойный, оригинальный Apple-inspired интерфейс. Главный принцип: любой механик без обучения понимает вердикт и дальнейшее действие за 10 секунд. Не копировать точный интерфейс Apple или чужих коммерческих продуктов.

## Визуальная система
- Manrope для латиницы/кириллицы, подходящие системные fallback для других письменностей; качественная читаемая типографика (body 14–16, большие вердикты).
- Светлая и тёмная темы на CSS variables; нейтральный фон, контрастный текст, аккуратные границы и умеренные скругления 8/12/20/24. Один основной акцент, красный/янтарный/зелёный только для статуса. Не полагаться только на цвет.
- Lucide, понятные текстовые подписи, функциональный feedback; без неона, стекла, чрезмерных градиентов, AI-slop, emoji, фото машин или бесполезных анимаций. Reduced-motion. Не тратить время на промо-лендинг.
- Использовать разрешённые универсальные идеи из своего Industrial Safety AI: shell, токены, диалог, EvidenceDrawer, журнал, адаптивность. Оригинальный репо неизменен, раскрыть реально использованное.

## Информационная архитектура
- Верх/сайдбар: «Диагностика», «Автопарк», «Заявки», язык и тема.
- Диагностика: поиск машины (госномер/гаражный номер/модель), текущая машина и сессия, действие запуска. Самое заметное — вердикт, запись, риск, рекомендуемый следующий шаг; детали раскрываются.
- Чат: голос + текст, быстрые уточняющие вопросы; короткие структурированные ответы, источники прямо у нормативов/действий. История проверок по текущей машине. Показать честный loading/error.
- Evidence drawer: документ, точная физическая PDF-страница, исходная цитата, отдельно ML-факты/гипотеза/ограничения; открыть оригинал, не загружать все PDF сразу. На смартфоне полноэкранная панель.
- Заявка: наглядный черновик, диагноз-гипотеза, основания приоритета, работы, детали при наличии, ссылки, явное подтверждение; успешный реальный номер, ошибка не замаскирована.
- Главный механик: состояние всех машин по последним проверкам, очередь внимания, фильтры, история/график, журнал заявок. Статусы 25/23/2 — исходные ML counts, не автоматически карантин. Без фальшивой статистики.
- Mobile: основное действие в пределах доступного экрана, крупные tap targets, без горизонтального скролла основных блоков, адаптивные таблицы, доступность источников/чата. Семь языков и длинные строки, без CSS обрезки технических сведений.

## UX-правила
Выделять факты/предположения, uncertainty и плохое качество записи; не использовать confidence как «шанс поломки». Нормативы только с источниками. Рекомендации практичные, но не автодопуск. При отсутствии доказательств — ясно сказать, что найдено/не найдено. Голосовой транскрипт можно исправить, заявку по неясной голосовой команде не отправлять.
