# Пакет сдачи JUDRIVE

Дедлайн по регламенту — **28.11.2026, 10:00 МСК**. [Правила и сроки](REGULATION.md)

## Текст для формы

**JUDRIVE — цифровой механик для грузового автопарка.** Механик выбирает автомобиль и акустическую проверку. Приложение получает результат Mock ML, показывает вердикт и подбирает страницы руководства по модели двигателя. Агент GigaChat использует отдельные инструменты диагностики, истории, поиска и подготовки черновика. После подтверждения сервер проверяет контекст и отправляет заявку в Mock ТОиР. Кабинет главного механика показывает приоритеты, динамику и журнал. Интерфейс адаптивен, локализован на семь языков и поддерживает голосовой ввод.

Стек — React/TypeScript/Vite, FastAPI/Python, SQLite FTS5, PDF.js, GigaChat и Docker Compose. Проект использует предоставленные Mock API. Окончательные решения о состоянии, дефектовке и допуске принимает механик. [Архитектура и запуск](../README.md)
