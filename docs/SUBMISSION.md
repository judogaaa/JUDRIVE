## Описание решения для формы

JUDRIVE — цифровое рабочее место механика грузового автопарка. Получает
структурированный результат предоставленного Mock ML по выбранной машине и
проверке, отображает его в посте диагностики и чате. Агент использует отдельные
инструменты диагностики, истории и поиска по применимым к двигателю руководствам.
Источники проверяются по документу и физической странице, PDF открываются внутри
интерфейса. При отсутствии достаточных сведений — честный отказ. Черновик заявки
в формате ТОиР v6 проверяется сервером, включает работы и источники; отправка
только после явного подтверждения механиком и получение фактического TKT.

Бонусы: обязательное обучение первого входа и центр «Помощь и обучение»
(12 карточек, поиск, FAQ, повторный запуск, 7 языков), память машины и
созданных заявок (не фактических ремонтов), динамика anomaly_score,
предупреждения, защищённый кабинет chief с категориями и приоритетами,
ручная обоснованная рекомендация карантина (не фактический карантин),
семь языков, голосовой ввод, адаптивный интерфейс,
светлая/тёмная/системная тема, поиск и связные переходы между диагностикой,
парком, PDF и заявками.

Стек: React/TypeScript/Vite, FastAPI/Python, SQLite FTS5, pypdf/pdfplumber/Poppler,
PDF.js, Groq GPT-OSS 120B с tool calling, Whisper для STT; оригинальные
Mock ML/ТОиР без изменения. Запуск: README, Docker Compose + Caddy для HTTPS,
PDF и переменные окружения предоставляются отдельно. Нет реальной ML-модели
для анализа звука двигателя, выполнения ремонта, подтверждения выпуска ТС,
прогноза даты отказа или интеграции с реальной 1С. OCR зависит от наличия ПО;
низкокачественный текст не считается доказательством. Лексическая проверка
работ не гарантирует семантическую правильность; окончательное решение специалиста.

## Как получить реальные цифры для Excel

На локальной копии БД с живыми замерами:
`python scripts/export_usage_cost.py --db local-data/judrive.sqlite`.
Скрипт сохраняет средние вход/выход, объём токенов и задержку в CSV.
При наличии подтверждённых тарифов передать `--input-usd-per-million`,
`--output-usd-per-million`, `--usd-rub`. Не переносить вымышленные значения:
тарифы проверить по аккаунту/договору, отдельно учесть STT и сервер. Указанные
токены относятся к завершённым сообщениям агента; частично неуспешные вызовы
и голосовые запросы нужно сверить с фактическим usage провайдера.

Локальный замер на 26.11: **55** завершённых LLM-сообщений,
178 787 total tokens (151 498 input, 27 289 output), средняя задержка 4 334 мс.
С подтверждёнными тарифами Groq ($0,15/$0,60 за 1 млн) и курсом ЦБ 82,313 ₽:
≈ $0,000711 / 0,0585 ₽ на сообщение, ≈ $0,0391 / 3,22 ₽ за весь замер.
Excel: `submission/JUDRIVE_usage_cost_2026-11-26.xlsx`; исходный CSV —
`submission/usage_cost.csv`; методика и ограничения — `submission/USAGE_EVIDENCE.md`.
STT: Whisper Large v3 Turbo $0,04/час; live smoke 0,4 с, стоимость ниже $0,001.
Инфраструктура локальная, платный сервер не использовался (0 ₽).
