Получите разрешённую ссылку у организатора и задайте её локально через `JUDRIVE_MANUALS_URL`.

Разрешённые `vehicles.json` и `fault_types.json` хранятся отдельно от кода. Backend читает парк через `FLEET_DATA_PATH`, оба Mock-сервиса через `MOCK_DATA_PATH`. Compose монтирует `JUDRIVE_FLEET_DIR` только для чтения. Код и схемы находятся в [vendor/neurodvs_mock](../vendor/neurodvs_mock/README.md).

Распакуйте PDF в приватный каталог. Задайте `PDF_DIR` для backend или `JUDRIVE_MANUALS_DIR` для Docker. Docker монтирует PDF только для чтения. Индекс SQLite с извлечёнными текстами хранится на приватном томе. [Отпечатки оригиналов](SOURCE_MANIFEST.json)

Запустите `python scripts/verify_original_manuals.py --pdf-dir /private/manuals`. Проверка сверяет SHA-256 и требует РЭ 31, РК 269, РК 276 в ответе о конфликте. Визуально сопоставьте формулировки, значения, единицы и условия. Проверяйте страницу 41 по перекрёстной ссылке, если её подтверждает оригинал. Само ожидание 15 минут не доказывает охлаждение.
