Внутренний архив имеет каталоги mock_ml, mock_toir, data (vehicles.json/fault_types.json), OpenAPI, requirements, README, тесты. Указанные данные синтетические. Оригинальный внутренний mock-пакет полностью распакован в [vendor/neurodvs_mock](../vendor/neurodvs_mock/README.md) без изменения байтов файлов: 13 файлов, включая обе заглушки, OpenAPI, синтетические данные, тесты, README, requirements и env.example. Для этапа 01 использовать его как supplied dependency; инструкции запуска в vendor README. Полный внешний архив, DOCX, записи брифинга и большие PDF не добавлены: полные документы требуют ясности прав на публичное распространение. Скачать шесть PDF из официального комплекта. Рекомендуемый путь — materials/manuals/ в корне клона, ровно шесть оригиналов с перечисленными именами. PDF_DIR указывает на этот каталог или абсолютный путь. materials/ игнорируется Git. На этапе 01 PDF не блокируют запуск ML/ТОиР; перед этапом 02 сверить наличие, хеши и количество страниц. Не индексировать случайные версии из интернета. [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) содержит исходные имена, размеры, SHA-256 и проверку совпадения отдельно полученных 6 PDF и 3 DOCX с архивом. Все фактические файлы для первичной интеграции доступны в репозитории; документы для RAG подключаются отдельно. Не копировать закрытые/личные материалы.
