В обязательном С2 задать именно вопрос о перегоне; вопрос о моменте затяжки — дополнительно, если хватает времени. С1–С3 обязательны для демовидео. С4 главный механик при готовности. Перед сдачей один краткий регрессионный проход, воспроизводимый запуск по README, проверить доступность всех ссылок из приватного окна. Без глобального пересчёта 195 сессий через LLM.
