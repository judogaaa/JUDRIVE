## Критерии этапа 01

- Команды запуска в README воспроизводятся. Данные из исходного файла; три статуса от настоящего Mock ML, при failed нет вывода о двигателе.
- UI реагирует на смену машины/сессии и ошибки, не показывает устаревший результат предыдущего запроса; нет ключа в клиенте.
- Проверена сборка и компактный smoke. Доступность Groq с хоста и HTTPS проверять рано, но не блокировать локальный этап.
- PROGRESS.md/TASKS.md отражают фактическую готовность. Коммит с нормальным сообщением; push после просмотра diff.
