# Пользовательский путь механика (JUDRIVE)

## Диагностика (P0)

1. Выбор машины (поиск + автопарк).
2. Автовыбор последней проверки; явный индикатор «Выбрана».
3. Кнопка «Получить результат диагностики».
4. Вердикт (normal / anomaly / check_failed) + блок «Следующие шаги».
5. Контекстные действия:
   - **Объяснить результат** → чат с фактами ML (auto-send).
   - **Что проверить?** → чат.
   - **Найти в руководстве** → раздел «Руководства», авто-поиск, при одном hit — PDF в drawer.
   - **Подготовить заявку** → чат (только anomaly, guardrails на backend).
   - **Скопировать план** → буфер обмена.
   - **Другая проверка** (check_failed) → фокус на селектор сессии.

## Сквозной контекст

- `vehicleId` / `sessionId` сохраняются при переключении разделов.
- Двигатель для руководств берётся из выбранной машины.
- Черновик заявки — только после подтверждения механиком.
