# API и уровни доступа JUDRIVE

API обслуживается под `/api` того же origin, что и интерфейс. Схемы и методы доступны в OpenAPI backend (`/openapi.json` при прямом локальном запуске). Прокси production маршрутизирует только `/api/*`.

| Доступ | Маршруты |
| --- | --- |
| Общий | `GET /api/live`, `GET /api/ready`, `GET /api/health`, вход, выход и состояние сессии |
| Главный механик и разрешённое демо | `GET /api/vehicles`, `GET /api/vehicles/{vehicle_id}/diagnosis-history`, `POST /api/diagnose` |
| Главный механик | `/api/manuals/*`, `/api/sources/*`, `/api/conversations/*`, `POST /api/voice/transcribe`, `GET /api/tickets`, `/api/tickets/drafts/*`, `/api/fleet/*` |

`POST /api/auth/login` принимает JSON `username` и `password` и возвращает роль `demo` или `chief`. Браузер передаёт HttpOnly-cookie при следующих запросах. `GET /api/auth/session` возвращает `authenticated` и `role`. `POST /api/auth/logout` удаляет cookie. Пять неверных попыток ограничивают новые попытки с того же клиентского адреса на 15 минут. Используйте доверенную настройку прокси приложения для определения адреса клиента. Анонимный запрос к рабочему API получает `401` при настроенном доступе, а запрос демосессии на закрытый маршрут получает `403`.

Демороль требует точного совпадения загруженного файла автопарка с `DEMO_FLEET_SHA256` для маршрутов автопарка и Mock ML. Она получает структурированный результат без свободного текста upstream. Доступ к исходным документам, диалогам, голосу, журналу и подтверждению заявок в эту роль не входит.

Диагностика принимает валидную пару `vehicle_id` и `session_id`. Для ручной работы с PDF передайте `engine_model`. Если запрос связан с диагностикой, передайте также оба идентификатора пары. Backend проверит применимость документа. PDF поддерживает запросы диапазона, страницы источников нумеруются с 1.

Голос принимает multipart с полем `file` и необязательным `locale`, до 8 МиБ. Чат и разбор заявки могут создать черновик только в соответствующем сценарии. Отправку вызывает отдельный запрос к `/api/tickets/drafts/{draft_id}/confirm` с актуальным `confirm_nonce` и явным подтверждением. Сохраняйте ручную сверку для неизвестного результата ТОиР.
